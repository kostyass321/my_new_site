# InkSoul — сайт тату‑салона

## Описание
InkSoul — это статический сайт тату‑салона, созданный на HTML, CSS и JavaScript. Сайт предназначен для презентации студии: здесь представлены портфолио мастеров, описание услуг, философия салона и атмосфера команды. Основная цель — помочь потенциальному клиенту быстро понять стиль студии, увидеть примеры работ и принять решение о записи.

## 🚀 Функциональность
- **Адаптивный дизайн**: сайт корректно отображается на мобильных устройствах, планшетах и десктопах.
- **Тёмная/светлая тема**: реализована через системные настройки ОС и CSS‑переменные; переключение происходит автоматически.
- **Навигация между страницами**: полноценное меню с переходами между разделами (Главная, О салоне, Портфолио, Услуги).
- **Поиск по контенту**: базовый поиск по заголовкам и описаниям реализован на JavaScript (без серверной части).
- **JS‑эффекты**: плавное появление карточек при прокрутке, интерактивные карточки мастеров, эффекты при наведении, плавный скролл к якорям.
